# Apex Motors 🚗

A lightweight web platform for luxury‑car dealerships to keep track of inventory, customers and sales—built with modern JavaScript and Oracle Cloud services.

---

## 🌐 Live Demo  
> Version 0.1 — *coming soon*

---

## ⚙️ Tech Stack  
- **Angular 17** – reactive UI & routing  
- **Node.js (Express)** – REST API layer  
- **Oracle Autonomous Database** – cloud SQL
- **Bootstrap 5** – responsive, mobile‑first design  

---

## ✨ Key Features  

| **Inventory** | Create, edit, archive and browse cars (brand, model, year, price, stock, images). |
| **Clients** | Customer profiles with contact info and lifetime spend. |
| **Orders** | Full purchase history per client and order‑status tracking. |
| **Sales Dashboard** | Real‑time KPIs—total cars, total revenue|
| **Responsive UI** | Works seamlessly on desktop, tablet and mobile. |
